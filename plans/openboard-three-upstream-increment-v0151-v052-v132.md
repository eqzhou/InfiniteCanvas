# OpenBoard 三参考线增量实施蓝图

状态：实施中（2026-08-18 续批次：公开最新功能）

冻结基线：Basket `v0.15.1`、Tiger `v0.5.2`、DramaClaw `v1.3.2`

计划变更：2026-08-18 登记 Tiger 公开 `v0.5.3`/`v0.5.4` 与 Basket CHANGELOG Unreleased，不读取实现源码。

当前检查点：S0/S0.5、S1、S5a 以及后续独立落地的 WebDAV 媒体开关、声音身份、风格提取、阶段豁免、Freestylefly 来源、定位缩放上限、多图槽位操作和导演台运镜时间线已完成 RED→GREEN。精确 GLM/MiMo/Seedance 2.5 仍为 `blocked-contract`。页面域完整双语迁移仍按 S2a–S2d 执行。

## 1. 目标与完成定义

在 OpenBoard 现有画布、工作台、影视制片、Agent、GenerationJob、PostgreSQL、Redis 和对象存储架构上，独立实现三条公开参考线中尚未覆盖、且对本产品有明确价值的行为。

“完成”必须同时满足：

- 有真实用户入口，不是仅存在于类型或测试中的帮助函数。
- 关键事实持久化到现有事实主线，刷新、重启和并发编辑后仍一致。
- 复用现有权限、租户隔离、额度、任务、审计和对象存储，不建设平行系统。
- 外部 Provider 只有在取得可核验的官方契约后才启用；未知模型继续 fail-closed。
- 每项执行 RED → GREEN → REFACTOR，并具备单元、集成或 E2E 证据。
- 不复制上游源码、补丁、CSS、提示词、素材、文案、图标或视觉设计。

本蓝图是工程行为计划，不构成源码、视觉、商标或法律等价声明。

## 3. 当前差异与产品决策

### 3.1 已覆盖，不重复实现

- Basket：本地 Skill 管理和画布生成草稿、多图候选状态与独立处理、选择/移动工具、长提示词编辑、Agent `/Skill` 和 `@画布素材` 元数据均已有实现和测试；本轮仍补完整跨入口 E2E，不能只凭组件存在宣称版本级覆盖。
- Tiger：图片/视频/音频工作台、Director、全景图、S3/R2、持久任务、工作流、精确视频尺寸派生和共享渠道管理均已有对应能力。
- DramaClaw：故事关系/节拍/人物弧、三种剧本模式、身份版本、制作资产、分镜、首尾帧、逐对白配音、质量修复、双轨画布、Director、五轨时间线、任务中心、Agent 和 MP4/SRT/资产包交付均已进入本地事实主线。
- DramaClaw v1.3.2 的“视频模式不得按参考图数量静默改写”已由 OpenBoard 的冻结 `generationMode`、能力目录和任务快照覆盖；只补跨入口回归，不重写执行器。

### 3.3 明确不做

- 不复刻 Basket/Tiger/DramaClaw 的名称、品牌、视觉外观、文案、提示词、素材或内置模板内容。
- 不引入第二套队列、第二套额度系统、第二套影视事实库或图数据库。
- 不建设 Tiger 桌面客户端；现有 PWA、PM2 和 Compose 已覆盖当前部署目标。若出现明确离线桌面需求，另立项目。
- 不在本轮实现 DramaClaw 可选 3GS、体素世界或全景转 3D GPU 管线；只预留 Director 环境资产扩展点，不把 GPU 依赖带入标准镜像。
- 不复制 DramaClaw 的创作伙伴人格、陪伴形象、气泡或主动打扰方式；现有 Film Agent 的状态、缺口和下一步建议记为 `compatible-different`。
- 不实现 OCR、专业 NLE 任意关键帧/蒙版/复杂特效、托管市场、支付、组织 SSO 或本地大模型安装器。
- 不根据上游模型别名猜测 MiniMax H3、MiMo 或 Seedance 2.5 请求字段；契约证据不足时对应步骤状态为 `blocked-contract`，而不是伪装完成。

## 4. 架构约束

- **事实主线**：画布项目继续使用 `BoardProject`；影视实体继续使用 PostgreSQL Film 聚合与实体/关系投影；媒体继续使用 `blobObjectStore` 和稳定 storage key。
- **任务主线**：所有文本、图片、视频、音频、风格提取和本地工作流均使用现有 `GenerationJob`、租约、幂等、取消、恢复和额度结算。
- **能力主线**：共享模型使用服务端版本化媒体能力目录；个人渠道只使用已验证的本地精确契约，不猜测能力。
- **版本与并发**：新增可编辑事实均带 `revision`；更新使用 CAS；生成任务冻结模型、模式、输入、价格、身份和风格版本。
- **不可变性**：采用候选时创建新版本，保留旧版本及来源；不得覆盖已批准声音、风格或镜头产物。
- **安全**：外部 URL、WebDAV、ComfyUI 和媒体下载统一经过 SSRF、DNS 重绑定、重定向、大小、MIME、时长和资源限制。

## 7. 跨步骤数据迁移

- 国际化只新增偏好和消息键，不改写用户内容。
- WebDAV 只新增提供者配置、placement 和迁移任务；旧 storage key 不变。迁移创建新对象版本及新 placement，再以 CAS 切换逻辑引用，旧 placement 延迟清理；任一对象版本始终只有一个不可变权威 placement。
- 声音身份、风格候选和阶段豁免使用向前兼容的新表/字段；旧 Film 文档迁移为空集合或默认关闭。
- GenerationJob 参数只增可选版本字段；旧任务保持原解析路径，新执行器不得重解释旧快照。
- 备份格式若需升级，导入器继续接受现有 v1/v2，预检失败整体回滚。

## 8. 计划变更协议

- **插入**：新上游版本或安全前置出现时，新增 `Sx.y`，写明依赖和范围，不悄悄扩大原步骤。
- **拆分**：单步超过一个可独立回滚 PR 时，按数据层/API/UI/迁移拆分，但共享验收保持不变。
- **阻塞**：连续确认缺少官方 Provider 契约时标记 `blocked-contract`，可继续其他步骤。
- **跳过**：仅 `not-targeted` 项可跳过，并在 `FEATURE_PARITY.md` 公开原因。
- **替代**：如果 OpenBoard 已有更安全或更完整的等价能力，记录 `compatible-different` 和验证证据，不为像素级相同而重写。
